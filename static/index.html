Target architecture · controls to validate

Future controlled cloud bursting

The AI Lab can later connect to a Secondary GPU Data Center and Cloud Souverain. Case and source classification, approved processing geography, destination approval and quotas determine eligibility. No external connector is active; unavailable approved capacity queues or refuses a job.

Case-specific controlled environments

A Controlled Project Environment (CPE) adds project isolation where case policy requires it. Approved speech processing can use a secured shared service without a dedicated CPE. Access tokens secure requests; inference tokens, audio duration and GPU time measure consumption.

Azure is a separate deployment decision

Synthetic data can support an Azure demonstration. Real recordings and case documents require explicit authorisation, an approved region and services, access policies and an agreed retention boundary before transfer.

What this release does not claim

No public LLM inference, live public speech recognition, trusted public identities or production institutional deployment. The target design adds embeddings, a local language model and bounded tool selection after evaluation.
